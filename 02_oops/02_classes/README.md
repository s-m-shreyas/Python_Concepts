# 02 Classes

This folder introduces the fundamental mechanics of Python classes and methods.

The goal is to understand how classes are defined, how objects are created, and how different types of methods interact with instances and classes.

---

## Topics Covered

| File | Concept |
|---|---|
| `01_class_definition.py` | Defining classes and class bodies |
| `02_class_body_execution.py` | How and when the class body executes |
| `03_object_creation.py` | Creating instances from classes |
| `04_instance_methods.py` | Defining and calling instance methods |
| `05_self_parameter.py` | The `self` parameter and current instances |
| `06_class_methods.py` | `@classmethod`, `cls`, and class-level behavior |
| `07_static_methods.py` | `@staticmethod` and methods without automatic binding |
| `08_method_binding.py` | How Python binds methods to instances and classes |

---

==============================================================================
Python Looping Statements
==============================================================================

Overview
--------
Loops are control flow statements that repeatedly execute a block of code
until a specified condition is no longer satisfied or until every element
of an iterable has been processed.

Python provides two primary looping constructs:

• for loop
• while loop

Additional control statements such as `break`, `continue`, `pass`, and
`loop else` modify the behavior of loops without changing their core
structure.

This section also covers commonly used iteration utilities such as
`range()`, `enumerate()`, and `zip()`.

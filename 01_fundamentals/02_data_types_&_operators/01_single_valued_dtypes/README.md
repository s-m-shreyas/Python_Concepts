# Single-Valued Data Types

Single-valued data types represent objects whose primary value is treated as
a single scalar value rather than a collection of multiple elements.

In this section, Python's numeric data types are explored individually, with
each module focusing on the behaviour, operations, properties, and applicable
built-in functions of that specific type.

# 06 - Functions

## Overview

Functions are one of the fundamental building blocks of Python programming.

A function is a reusable block of code designed to perform a specific task.

Instead of repeatedly writing the same logic, we can place that logic inside
a function and execute it whenever required.

This folder covers Python functions from basic definitions through
advanced concepts such as higher-order functions, recursion, and callable
objects.

---

## Learning Objectives

By completing this folder, you should understand:

- How to define a function
- How to call a function
- How parameters work
- How arguments are passed
- Positional arguments
- Keyword arguments
- Default arguments
- `*args`
- `**kwargs`
- Return values
- Multiple return values
- Variable scope
- `global`
- `nonlocal`
- Nested functions
- Function annotations
- Docstrings
- Lambda functions
- First-class functions
- Higher-order functions
- Recursive functions
- Callable objects

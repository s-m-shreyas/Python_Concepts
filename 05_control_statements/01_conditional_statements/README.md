# Conditional Statements

This directory demonstrates Python's decision-making constructs used to execute different blocks of code based on one or more conditions.

Conditional statements form the foundation of program logic by allowing applications to make decisions dynamically at runtime.

The implementations in this directory prioritize readability, practical understanding, and clean coding practices.

---

## Contents

| File | Description |
|------|-------------|
| `01_if_statement.py` | Basic conditional execution using `if` |
| `02_if_else_statement.py` | Two-way decision making using `if-else` |
| `03_if_elif_else_statement.py` | Multiple condition branching |
| `04_nested_if.py` | Nested conditional statements |
| `05_ternary_operator.py` | Conditional expressions using Python's ternary operator |
| `06_match_case.py` | Pattern matching using `match-case` (Python 3.10+) |

## Best Practices

- Keep conditions simple and readable.
- Avoid excessive nesting whenever possible.
- Use `elif` instead of multiple independent `if` statements when only one branch should execute.
- Prefer `match-case` when handling multiple discrete values (Python 3.10+).

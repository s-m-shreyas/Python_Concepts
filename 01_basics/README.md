# Python Basics

## Overview

The Basics module introduces the fundamental building blocks of Python programming.

Before learning data types, operators, functions, or object-oriented programming, it is essential to understand how Python programs are written, how variables are created, how user input and output work, and the conventions used to write clean and readable code.

This module provides the foundation upon which the rest of the repository is built.

---

# Topics Covered

## Python Fundamentals

- Hello World
- Python Comments
- print() Function
- Input Function
- Variables
- Constants
- Naming Conventions
- Type Hints

---

# Learning Objectives

After completing this module, you should be able to:

- Write and execute basic Python programs.
- Understand Python syntax and indentation.
- Display output using the `print()` function.
- Accept user input using the `input()` function.
- Declare and use variables.
- Follow Python naming conventions.
- Use constants appropriately.
- Apply basic type hints for improved code readability.

# Why Learn the Basics?

A strong understanding of Python fundamentals helps you:

- Read Python code confidently.
- Write clean and maintainable programs.
- Understand later topics more easily.
- Avoid common beginner mistakes.
- Build good programming habits from the beginning.

---

# Best Practices

- Follow the Python Style Guide (PEP 8).
- Use meaningful variable names.
- Write clear and concise comments only when necessary.
- Prefer descriptive constants over magic values.
- Use type hints to improve code readability.
- Keep code simple and easy to understand.

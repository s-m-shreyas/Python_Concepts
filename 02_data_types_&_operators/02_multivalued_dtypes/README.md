# Multi-Valued Data Types

This folder covers Python data types that can store or represent
**multiple values within a single object**.

Unlike single-valued data types such as:

- `int`
- `float`
- `complex`

these data types can contain multiple elements, characters, key-value
pairs, or bytes.
